THE HUMAN CONDITION

Museum of the Recorded Human · 2046

项目更新版本：V3.0

一、整体概念：已确定

这是一座设定于2046年的未来博物馆。

通过保存、分类、重建和解释2026年人类留下的数字记录，让未来的人理解AI时代的人类社会。

作品采用互动艺术装置的形式，而非传统知识问答游戏。

核心方向：

* 2026年的社会文化状态
* AI与人类的关系
* 数字身份与身体数据化
* 算法与信息环境
* 情绪、人际关系和集体记忆
* AI辅助表达与数字真实性

博物馆使用已经确定的主体建筑和六个展区。

建筑结构与此前确认的视觉参考保持一致。

所有艺术作品必须是独立可编辑的3D对象，并支持交互。

二、12件作品的最新状态

001｜The Multiple Selves 多重自我

状态：✅ 已确定

内容：一个人在数字时代拥有不同的身份、社会角色和想象中的人生版本。

造型：透明树脂多面孔雕塑，采用短颈、宽肩、分枝生长的整体结构。

禁止使用超长脖子、蘑菇状堆积人头的造型。

交互：点击不同身份，增加对应的独立面孔模型，并与原始雕塑相互穿透。

状态：⏳ 待定

此前的金属抽屉与24小时时间线方案尚未最终确定。

不得将旧方案作为最终版执行。

003｜Cultural Creation 文化创作

005｜The Weather of Emotion 情绪的天气

状态：✅ 已确定

内容：数字记录无法完整保存人的情绪与主观经验。

形式：室内云、雨、雾、声波和情绪记录。

交互：切换不同背景记录，触发不同天气变化。

006｜The Quantified Body 被量化的身体

状态：✅ 已确定

内容：人的身体如何被数字系统拆解成可测量的功能。

形式：人体雕塑、重复手臂、动作轨迹、生理记录、姿态结构。

交互：点击不同数据类别，增加相应身体结构。

要求：所有数据标签、记录时间、测量指标、数据来源及解释都需要可见。

007｜Human Relationships 人际关系

状态：⏳ 待定

暂时保留AI时代人际关系的研究方向。

之前的双人面对面、聊天误解与透明度变化方案尚未确定，不得直接执行。

008｜The Algorithmic Filter 算法过滤

状态：✅ 已确定

内容：人对某类内容的重复选择，会影响后续接触到的信息。

形式：图像、图案、符号和颜色构成的三维空间。

交互：点击某类图案后，相同或相似图案不断复制增殖，其他类别逐渐减少。

尽量通过视觉变化表达，不依赖大段文字。

重点：信息世界逐渐变得重复、单一。

009｜Collective Memory / Mandela Effect 集体记忆错位

状态：🟡 主题已确定，具体形式待定

内容：同一段文化或历史记忆，在不同群体中存在不一致的版本。

不得再使用AI修复家庭照片的旧版方案。

可研究的实例包括：
《爱我中华》歌词、皮卡丘尾巴、大富翁先生、好奇猴乔治、C-3PO等。

B. 记忆投票塔

C. 档案翻牌墙

D. 儿童记忆剧场

尚未最终选择。

010｜The Invisible Rules 隐形规则

状态：🟡 艺术方向已确定，交互机制待定

参考用户艺术作品《Invisible Prison》。

核心视觉：空间看起来透明、开放，观众能够看到外部世界，却被不可见的边界阻挡。

候选表达：

透明监狱走廊。

可见的世界、不可达的世界。

会根据不同条件出现的透明障碍。

此前两个申请者通过不同大门的案例废弃。

该作品与008的区别：

008研究信息可见性的筛选。

010研究规则与行动边界的限制。

011｜The Last Human Message 最后的人类信息

状态：✅ 主题与三层结构已确定

内容：AI辅助表达过程中，人的原始意图如何被整理、修改和重新生成。

采用三个文本版本：

第一层：人类原文。

第二层：AI润色。

第三层：AI根据同一主题重新生成。

测试文本：

原文：
“我觉得这个方案好像不太行，我想先看看别的，暂时不要做。”

AI润色：
“我对目前的方案仍有一些疑虑，希望在作出决定之前，先评估其他可能性，因此建议暂缓执行。”

AI生成：
“这个方案具有一定潜力，可以先启动初步测试，再根据实际反馈逐步优化。”

重点表现三个版本之间的语义偏移。

以上内容暂时作为测试文本，尚未作为最终展出材料。

012｜The Fragile Truth 脆弱的真相

状态：✅ 已确定

内容：经过生成、修改和传播后，原始数字证据如何被遮蔽。

形式：大量混乱叠加的透明影像、照片、数据和证据层。

交互：

初始状态几乎无法看清原始影像。

观众关闭、移除或穿过不同的信息层。

随着干扰减少，原始图像逐渐显现。

必须具有强烈的空间层次与视觉混乱感。

不可再做成与011相同的三块整齐文字屏幕。
